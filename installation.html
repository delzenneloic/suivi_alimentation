Retour au journal

À table, sur ton téléphone.

Au quotidien

  1. Ouvre le journal. La date et le type de repas sont proposés automatiquement.
  2. Prends une ou plusieurs photos et ajoute quelques mots si tu veux.
  3. Touche Envoyer. Choisis ton compte Google si la connexion est demandée.
  4. Attends la confirmation Repas enregistré.

Ajoute l’adresse à ton écran d’accueil depuis le menu de Safari ou Chrome. Le journal peut s’ouvrir hors ligne après une première ouverture réussie ; l’envoi nécessite internet et l’application ouverte.

Connexion Google

L’identifiant public de ton application de tickets est déjà renseigné. Sur https://delzenneloic.github.io, il réutilise la même origine que les tickets.

Si Google indique une origine non autorisée, ouvre le client web dans la console Google Cloud et ajoute https://delzenneloic.github.io aux origines JavaScript autorisées, sans chemin après le domaine. Vérifie que Google Drive API est activée. Si le projet est en mode test, le compte doit figurer parmi les utilisateurs de test.

Pour un essai local : autorise http://localhost:4173 et http://localhost, puis utilise npm start. Le site doit être servi en HTTPS en production. Aucun secret client n’est nécessaire.

La connexion peut être redemandée à la réouverture du journal ou à l’expiration de la session. Les accès Google restent uniquement en mémoire.

Où sont les données ?

Dans suivi_alimentation / aaaa.mm, directement dans ton Drive. Pour chaque repas : un JSON, puis les images nommées avec le même horodatage et les numéros _1, _2, etc. Le mois et l’horodatage correspondent à l’heure locale du repas, même si tu envoies plus tard.

Chaque description est conservée telle que tu l’as écrite. Les quantités sont facultatives. Aucune estimation automatique de calories ou de nutriments n’est produite.

Les images originales sont conservées, jusqu’à 25 Mo chacune et 20 photos par repas. L’aperçu HEIC dépend du navigateur ; l’envoi reste possible.

L’accès Google est limité aux fichiers accessibles à cette application. Un dossier créé manuellement peut être invisible avec cette autorisation : laisse l’application créer son dossier lors du premier envoi.

Si la connexion coupe

Le brouillon et les repas en attente restent sur cet appareil. Touche Envoyer les repas en attente une fois reconnecté. Un transfert commencé reste lié au compte Google initial. Les identifiants de fichiers sont conservés pour reprendre sans recréer les mêmes fichiers.

Les photos sont envoyées avant le JSON : tant qu’il manque une photo, le repas n’est pas confirmé. Quelques photos isolées peuvent temporairement être visibles dans Drive pendant un envoi interrompu.

Le stockage du navigateur est temporaire : effacer les données du site ou manquer d’espace peut supprimer les brouillons. Attends la confirmation dans Drive avant de les considérer sauvegardés. Les copies des photos sur l’appareil sont libérées après confirmation de l’envoi.
